# Usuarios Demo

Todos los usuarios demo se crean desde `DatabaseSeeder` y usan la contraseña:

`password`

| Email | Rol | Uso recomendado |
| --- | --- | --- |
| `superadmin@demoips.test` | Super Admin | Probar acceso global y administracion total. |
| `admin@demoips.test` | Administrador de empresa | Probar administracion completa de la empresa demo. |
| `medico@demoips.test` | Médico/a | Probar módulo clínico: consultas, recetas, citas, etc. |
| `recepcion@demoips.test` | Recepción | Probar agendamiento, admisiones y caja. |
| `ventas@demoips.test` | Ventas | Probar CRM: leads, clientes, deals, actividades, pedidos. |
| `inventario@demoips.test` | Inventario | Probar inventario: productos, bodegas, movimientos, proveedores, ordenes de compra. |

Permisos por rol en [docs/roles-permissions.md](roles-permissions.md).
