# Usuarios Demo

Todos los usuarios demo se crean desde `DatabaseSeeder` y usan la contraseña:

`password`

| Email | Rol | Uso recomendado |
| --- | --- | --- |
| `superadmin@vetlosandes.co` | Super Admin | Probar acceso global y administracion total. |
| `admin@vetlosandes.co` | Administrador de empresa | Probar administracion completa de la empresa demo. |
| `ventas@vetlosandes.co` | Ventas | Probar CRM: leads, clientes, deals, actividades, pedidos. |
| `inventario@vetlosandes.co` | Inventario | Probar inventario: productos, bodegas, movimientos, proveedores, ordenes de compra. |
| `usuario@vetlosandes.co` | Usuario | Probar el acceso base (solo dashboard). |

Permisos por rol en [docs/roles-permissions.md](roles-permissions.md).
