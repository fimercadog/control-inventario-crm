# Usuarios Demo

Todos los usuarios demo se crean desde `DatabaseSeeder` y usan la contraseña:

`password`

| Email | Rol | Uso recomendado |
| --- | --- | --- |
| `superadmin@esteticaelite.co` | Super Admin | Probar acceso global y administración total. |
| `admin@esteticaelite.co` | Administrador de empresa | Probar administración completa de la empresa demo. |
| `medico@esteticaelite.co` | Médico/a Especialista | Probar valoraciones, consultas, diagnósticos y procedimientos estéticos. |
| `medica@esteticaelite.co` | Médico/a Especialista | Probar atención médica estética y prescripciones. |
| `recepcion@esteticaelite.co` | Recepción | Probar agendamiento, pacientes, servicios y recepción. |
| `inventario@esteticaelite.co` | Inventario | Probar productos dermoestéticos, insumos, bodegas y compras. |
| `ventas@esteticaelite.co` | Ventas | Probar CRM: leads, clientes, tratamientos, actividades y cotizaciones. |

Permisos por rol en [docs/roles-permissions.md](roles-permissions.md).
