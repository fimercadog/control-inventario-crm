# Referencia visual del sitio público

El sitio de marketing replica el **SaaS Product Layout Pack** de Divi / Elegant
Themes (categoría *Technology*). Fidel tiene membresía **Divi "Themes & Plugins"
Lifetime**, así que usar y adaptar este pack en el proyecto es uso autorizado.

## Enlaces oficiales

| Librería completa de layouts | https://www.elegantthemes.com/layouts/ |

El pack se descarga desde dentro de Divi (gratis para clientes Divi) o desde el
post. Incluye 8 layouts + footer: **About, Blog, Contact, Documentation,
Features, Home, Landing, Pricing**.

## Licencia de los assets

Los assets del pack (íconos, ilustraciones, fotos) **no tienen restricciones de
licencia**: se pueden usar en proyectos comerciales sin pagar regalías ni
atribuir. (Fuente: post oficial de Elegant Themes.)

## Dirección visual resumida

- Fondo **blanco**, tinta **casi negra**, acento **verde medio** (`#15803d`),
  bandas/tarjetas **azul marino** (`--ink` / `--navy`).
- Titulares de hero en **peso 900** (`font-black`).
- **Tarjetas tipo widget oscuras** (gauge / barras / stat / avatar) flotando
  sobre **blobs de degradado verde→lima**.
- Capturas del producto **inclinadas en perspectiva 3D**.
- Botones **pill**. Tipografía **Roboto**.
